# IFP / 面板 / 零組件時價趨勢網站

此專案提供一個可直接開啟的前端頁面，聚焦：

- 全球面板（LCD/OLED）價格來源整理
- IFP（互動式電子白板）相關供應鏈資料來源
- 觸控/鋼化玻璃來源
- SSD / 記憶體（DRAM / NAND）價格來源
- 可拖曳日期拉桿（歷史 + 未來預測）

## 啟動方式

```bash
python3 -m http.server 8000
# 開啟 http://localhost:8000
```

## 客製化

- 可修改 `app.js` 的 `sourceDirectory` 擴充來源。
- 若你有付費報價平台資料，可把 CSV 轉換後掛到 `importData()`。
